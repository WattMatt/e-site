# Enterprise construction platforms — what E-Site v2 can learn

Research date: 2026-09-09. Scope: Procore, Autodesk Construction Cloud (Build / BIM 360 / PlanGrid lineage, now branded "Forma"), Oracle Aconex, Buildertrend, Trimble ProjectSight (+ Viewpoint Team). Method: vendor help centres and press releases first, then third-party pricing/review aggregators. Reddit blocks crawlers, so community sentiment is taken from Capterra/G2 summaries, Contractor Talk and the vendors' own idea portals.

---

## 1. Procore

**IA.** Two levels only: *Company* (Portfolio, Directory, 360 Reporting, Admin) and *Project*, where every project has a Home/"Project Overview" and a flat, horizontal list of tools (RFIs, Submittals, Drawings, Daily Log, Change Events, …). The Project Overview shows address + weather, then a **tool-by-tool count of open items with a three-bucket bar chart: overdue / due in 7 days / due in >7 days**, "My Open Items", "recently changed items", and today's schedule tasks ([support.procore.com — About the Project Home Page](https://support.procore.com/products/online/user-guide/project-level/home/tutorials/about-the-project-home-page)). The legacy Home is being sunset in favour of this overview.

**Daily loop.** "My Open Items" exists at three levels — Portfolio (cross-project), Company Home and Project Home — listing every item where the user is the action-owner, by project, item type and status, **sorted by due date**, exportable to PDF/CSV/Excel ([View My Open Items in the Portfolio Tool](https://support.procore.com/products/online/user-guide/company-level/portfolio/tutorials/view-my-open-items-in-the-portfolio-tool); [FAQ](https://support.procore.com/faq/is-there-a-way-to-see-all-the-open-items-in-procore-assigned-to-me)). For the site user the loop is Daily Log + photos + observations on mobile; the PM's is My Open Items + the overdue bar on Overview.

**RFI / submittal / change model — the canonical "ball in court" (BIC).** An RFI has a *Creator*, an *RFI Manager* (gatekeeper, usually the GC PM), one or more *Assignees* and a *Distribution list*. BIC is a **single derived field** stating who owes the next action: Assignee(s) while responses are outstanding, back to the RFI Manager once all required responses are in, and to a forwardee if an assignee forwards it. Multiple assignees *share* BIC until every required response lands. BIC can be shifted manually by the Manager and that shift always emails the new holder even if no other notification is ticked ([Shift the Ball In Court](https://support.procore.com/products/online/user-guide/project-level/rfi/tutorials/shift-the-ball-in-court-on-an-rfi); [When does the RFIs tool send emails](https://support.procore.com/faq/when-does-the-rfis-tool-send-email-notifications)). Due date defaults from a project-level "days to respond" setting; **overdue reminders go only to the current BIC holder** (a community thread complains they also hit assignees who already answered — the edge case to test) ([community.procore.com](https://community.procore.com/s/question/0D52T00005JTh4iSAD/why-do-overdue-rfi-emails-get-sent-to-assignees-who-have-already-responded-and-are-no-longer-the-ball-in-court)). An "official response" is distinguished from discussion responses. Submittals use the same shape with a *Submittal Manager* and a workflow of steps; one user per step = sequential, several = parallel, and BIC does not advance until every parallel approver responds; an "Approvers' Response Time" report measures each reviewer's days-to-respond ([sequential vs parallel FAQ](https://support.procore.com/faq/whats-the-difference-between-sequential-and-parallel-approval-in-the-submittal-workflow); [response-time report](https://support.procore.com/products/online/user-guide/project-level/submittals/tutorials/view-the-submittal-approvers-response-time-report)). Change: *Change Event* (cost-neutral placeholder) → *Potential Change Order* → contract-tiered Change Order, with DocuSign for signatures ([Change Orders workflow diagrams](https://support.procore.com/products/online/user-guide/project-level/change-orders/workflow)).

**Documents/drawings.** Drawings tool with automatic revision sets, OCR auto-hyperlinking of callouts, overlay compare (blue additions / red deletions), and markups that link to RFIs, submittals, photos and punch items so an annotation becomes a hyperlink ([ZenTek hidden gems](https://zentekconsultants.net/procores-hidden-gems/); [feedback thread on compare](https://feedback.procore.com/forums/183340-customer-feedback-for-procore-technologies-inc/suggestions/13063551-drawing-overlay-comparison-tool-compare-drawings)).

**Notifications / email.** Every RFI email is a *reply-to* address bound to the RFI; the architect hits Reply, types, attaches, sends — the reply (with attachments) is posted to the Responses card and fan-out emails go according to the project's per-event matrix (rows = events, columns = roles) ([Respond to an RFI](https://support.procore.com/products/online/user-guide/project-level/rfi/tutorials/respond-to-an-rfi)). Procore's marketing line is literally "architects and engineers can reply directly from email without logging in" ([procore.com/rfis](https://www.procore.com/project-management/rfis)). External parties never pay: unlimited users including subs, clients and consultants ([Invite users and collaborators](https://support.procore.com/products/online/user-guide/company-level/directory/tutorials/invite-users-and-collaborators-to-your-companys-procore-account)).

**Reporting.** Per-tool canned reports plus "360 Reporting" custom builder (multi-tool joins, group/filter, dashboards) with **scheduled distribution to users or distribution groups as PDF/Excel/CSV** ([Distribute a snapshot of a 360 report](https://support.procore.com/products/online/user-guide/company-level/reports/tutorials/enhanced-reporting-distribute-a-snapshot-of-a-report)).

**Praise / complaints.** Praised: breadth, support, BIC accountability, drawings. Top 3 complaints: (1) price — sales tells 6–12-person firms it "wasn't designed for companies their size"; (2) onboarding takes weeks to months; (3) inconsistency between tools (some autosave, some don't; name ordering differs) and a clunkier mobile app ([Capterra](https://www.capterra.com/p/56250/Procore/), [G2 pros/cons](https://www.g2.com/products/procore/reviews?qs=pros-and-cons), [Constructable](https://constructable.ai/blog/procore-reviews-pricing-alternatives)).

**Pricing.** Annual fee by product, sized on **Annual Construction Volume**, unlimited users/storage; ~0.1–0.2% of ACV; $15–30k/yr for $10–50M GCs, $30–80k/yr for $50–200M; implementation $50–150k+ first year ([procore.com/pricing](https://www.procore.com/pricing); [Scan Manifold](https://www.scanmanifold.com/blog-posts/procore-pricing-2026-contractors)).

**AI (2025–26).** *Procore Helix* intelligence layer; *Procore Assist* (ex-Copilot): conversational Q&A over specs/RFIs/submittals/codes, photo intelligence (progress + safety from site photos), multilingual (ES/PL/FR/PT), mobile voice; *Agent Builder* (open beta Oct 2025) for custom agents drafting RFIs, managing submittals, generating daily logs — 1,000+ agents built at Groundbreak ([press release, 2025-10-15](https://www.procore.com/press/procore-advances-the-future-of-construction-with-new-ai-innovations)).

## 2. Autodesk Construction Cloud (Build / Docs; BIM 360 → PlanGrid → ACC → Forma)

**IA.** Account → Projects → per-project modules (Docs: Files, Sheets, Specifications, Reviews, Transmittals, Issues; Build: RFIs, Submittals, Forms/Daily Logs, Assets, Cost, Schedule, Meetings; Insight: dashboards). The cross-project **My Home dashboard** (Sept 2025) is card-based: *Assigned to Me*, *Recent Items*, *My Projects*, *Bookmarks*, plus 150+ library cards incl. partner cards (Power BI, EarthCam) ([IMAGINiT](https://resources.imaginit.com/building-solutions-blog/personalized-insights-at-your-fingertips-introducing-dashboards-in-autodesk-construction-cloud); [Autodesk partner cards](https://www.autodesk.com/blogs/construction/improve-project-visibility-with-autodesk-construction-cloud-partner-cards/)).

**Daily loop.** "Assigned to Me" card + Issues + Forms (daily logs, checklists) on mobile with offline sync. Email frequency is per user: instant / hourly / daily digest sent 04:00 project time, some events always instant ([Email notification settings](https://help.autodesk.com/view/DOCS/ENU/?guid=Admin_Notifications)).

**Workflows.** RFI roles: *Creator → Manager → Reviewer (+ optional Coordinator)*; **RFI Types** preset default reviewer/coordinator per discipline (e.g. an "electrical" type routes to the electrical consultant automatically) ([Autodesk blog](https://www.autodesk.com/blogs/construction/rfi-submittal-review-workflows-autodesk-build/)). Submittals: custom multi-step workflows, several reviewers per step, each giving a formal response; the Submittal Manager is gatekeeper. The list shows both a *Ball in court* column and a *Pending action from* column (who in the current step has not yet answered); BIC can be a **role or a company**, not just a person ([Process submittal items](https://help.autodesk.com/view/BUILD/ENU/?guid=Process_Submittal); [idea: fixed due dates](https://forums.autodesk.com/t5/forma-for-construction-ideas/fixed-submittal-due-dates/idi-p/14160767)). Reply-by-email: "when an RFI recipient is ball-in-court they can reply to the email directly and their response will be recorded", attachments auto-uploaded ([RFI Email Notifications and Replies](https://help.autodesk.com/view/BUILD/ENU/?guid=RFI_Notifications)).

**Documents.** Files with versioning and permissions; Sheets with auto-title-block extraction and hyperlinked callouts; **Reviews** (structured approval workflows; statuses approved / approved with comments / rejected, full who-when-what record); **Transmittals** (formal issue of files at fixed versions to recipients *who need not be project members*, with cover message); version compare during review; Packages as review containers ([Review and Approve Files](https://help.autodesk.com/view/DOCS/ENU/?guid=Reviews_Review_and_Approve); [Revit Monsters on Forma](https://revitmonsters.org/en/articles/what-is-autodesk-forma)).

**Reporting.** Insight dashboards (project + account), scheduled reports per module, Data Connector to Power BI.

**Praise / complaints.** Praised: model + document interoperability, Docs as CDE. Complaints: (1) per-user, per-module licensing that is "tricky" and expensive for full-access teams; (2) less intuitive than Procore, steeper learning curve; (3) notification floods — a top-voted idea asks for in-app notifications "instead of multiple emails" ([Capterra ACC](https://www.capterra.com/p/218046/Autodesk-Construction-Cloud/); [G2 compare](https://www.g2.com/compare/autodesk-construction-cloud-vs-procore); [Autodesk ideas](https://forums.autodesk.com/t5/forma-for-construction-ideas/notifications-on-the-web-page-instead-of-multiple-emails/idi-p/12447918)).

**Pricing.** Per named user per product: Docs ~$35–45/user/mo, Build ~$75–85/user/mo, BIM Collaborate Pro ~$100–120; Build ~$1,625/user/yr list ([contractorsandbuilders.com](https://contractorsandbuilders.com/pricing/autodesk-acc/); [construction.autodesk.com/pricing](https://construction.autodesk.com/pricing/)). This is the opposite bet to Procore/Aconex/Buildertrend.

**AI.** *Autodesk Assistant* (2025, within Forma): natural-language search across specs, RFIs, issues, submittals, meetings, change orders and schedules; drafts emails/RFIs/reports; prompt library; e.g. "Summarize submittals overdue for approval and their impact on milestones" ([Meet Autodesk Assistant](https://www.autodesk.com/blogs/construction/meet-autodesk-assistant-ai-native-intelligence-in-forma/)). Geometry-based assistants announced ([ENR](https://www.enr.com/articles/61362-autodesk-folds-construction-cloud-into-forma-will-release-geometry-based-ai-assistants)).

## 3. Oracle Aconex

**IA.** Project-centric, *organisation-neutral*: every organisation on the project has its own private workspace and controls what it shares and when; nothing is deletable once transmitted ([oracle.com/aconex](https://www.oracle.com/construction-engineering/aconex/)). Modules: Mail, Documents (register), Workflows, Models, Field, Packages, Insights. Landing page is **Tasks** — "all the mail and other processes requiring your action on this project", with Documents and Workflows sections below ([Tour of the Tasks page](https://help.aconex.com/tasks/tour-of-the-tasks-page/)).

**Daily loop.** Tasks page = Outstanding mail (needs your response by a date), Overdue mail (past its response-required date), unread transmittals, and workflow review steps; email notifications deep-link to the same items ([Managing your mail via the Tasks page](https://help.aconex.com/tasks/managing-your-mail-via-the-tasks-page/)).

**Workflows — the correspondence model.** Everything (RFI, Site Instruction, Variation Request, Technical Query, Transmittal) is a **typed Mail** with a project-configured form, numbered per organisation, with a *Response required* field that admins can make mandatory so a due date is always set ([Making Response Required mandatory](https://help.aconex.com/project-admins/making-response-required-mandatory-for-mail-types/); [RFI implementation](https://help.aconex.com/implementation/request-for-information-rfi/)). A *process* is the chain of mails; BIC is defined at **organisation** level: "the 'To' recipients of the latest mail with a response required", flipping to the sender once a reply arrives, N/A when closed; Insights reports overdue-by-BIC-organisation ([Process metric definitions](https://help.aconex.com/insights/process-metric-definitions/)). April 2026 added *Document Process* with an automated **Review Matrix** that starts the right approval flow from document metadata and distributes in a pre-agreed sequence, plus ITP *Test Plans* tied to version-controlled documents ([Oracle press release, 2026-04-13](https://www.oracle.com/news/announcement/new-oracle-aconex-capabilities-improve-project-transparency-and-control-2026-04-13/)).

**Documents.** Document register with per-organisation numbering, manual or automatic revision scheme, full revision history; a Transmittal is a mail type that automatically shares the attached revisions into the recipient's register; workflow transmittals carry documents to review; online viewer with markups; "Transmitted versions vs Latest versions" toggle ([Transmit your document](https://help.aconex.com/documents/transmit-your-document/); [Review documents from a workflow transmittal](https://help.aconex.com/workflows/review-documents-from-a-workflow-transmittal/)).

**Notifications / external parties.** Email notifications per user; the historic pricing model made one organisation pay and *all* participants free: project-unlimited, enterprise-unlimited, or per-user (introduced for sceptical US buyers) ([Saniel Ventures — Aconex Unlimited](https://saniel.vc/pricing-to-drive-network-growth-aconex-unlimited/)). Oracle now quotes custom subscriptions ([Software Finder](https://softwarefinder.com/project-management-software/aconex)).

**Reporting.** Insights dashboards (mail process metrics, document review cycle times), Construction & Engineering Analytics with prebuilt pipelines over Aconex/P6/Unifier ([Oracle C&E Intelligence](https://www.oracle.com/construction-engineering/intelligence/)).

**Praise / complaints.** G2 4.5/5 (231 reviews); document management scored 9.6. Complaints: layout "clunky and not self-intuitive", having to refresh the register several times before updates show, heavy learning curve, enterprise-only pricing ([G2](https://www.g2.com/products/oracle-aconex/reviews); [Capterra](https://www.capterra.com/p/220249/Oracle-Aconex/reviews/)). Note: a G2 comparison page claims Aconex is "discontinued"; that is wrong — it is actively sold and shipped new features in April 2026.

**AI.** *Advisor for Safety* (GA Mar 2026): weekly risk forecasts picking the 20% of projects likely to cause 80% of incidents, with customer-reported incident reductions of up to 50% ([Oracle, 2026-03-05](https://www.oracle.com/news/announcement/oracle-transforms-construction-safety-management-with-ai-2026-03-05/)); generative analytics in C&E Intelligence.

## 4. Buildertrend (residential; included as the SME benchmark)

**IA.** Five top-level areas — Sales, Jobs, Project Management (schedule, daily logs, to-dos, change orders, selections, warranty, time clock), Files, Messaging, plus Financials; each job has a summary screen ([Workyard review](https://www.workyard.com/compare/buildertrend-review); [Buildertrend product overview](https://buildertrend.com/product-overview/)). **Daily loop:** dashboard shows "everything you must accomplish for the day and the week"; crews file daily logs with photos; the homeowner opens the branded **client portal** for schedule, photos, pending change orders, selections and payments, and approves change orders from a phone ([Buildertrend daily logs](https://buildertrend.com/project-management/daily-logs/)). **Change orders** are client-facing with e-signature; selections flow into change orders and budget automatically. **Notifications:** per-user settings and an admin-only log of every email sent with timestamps/recipients ([Buildertrend glossary](https://buildertrend.com/help-article/buildertrend-glossary/)).

**Pricing / complaints.** Essential $339 / Advanced $499 / Complete $829 per month (annual), unlimited users and projects, demo-gated, estimating locked to Advanced+; **renewal hikes of 50–75%** are the dominant complaint (a Contractor Talk thread reports +65%); also only one client login per project, manual daily-log templates, a steep learning curve and a weaker mobile app ([Contractor ToolStack](https://contractortoolstack.com/software/buildertrend/); [Contractor Talk](https://www.contractortalk.com/threads/buildertrend-price-hike.447579/); [Connecteam review](https://connecteam.com/reviews/buildertrend/)).

**AI.** *AI Client Updates* (Jun 2025) drafts a weekly homeowner summary from Daily Logs, Schedule, Change Orders and Invoices (one week back, one forward); users report 97% less time, ~6.5 min per update ([press release](https://buildertrend.com/press-releases/buildertrend-launches-ai-tool-for-97-faster-client-updates/)).

## 5. Trimble ProjectSight (and Viewpoint Team)

**IA / loop.** One project record with Budget, Drawings, RFIs, Submittals, Issues, Daily Reports, Photos, Specs, Punch; free mobile app; 360 Capture links walkthrough video to drawings and RFIs ([trimble.com/projectsight](https://www.trimble.com/en/products/projectsight)). Connects to Viewpoint Vista/Spectrum ERPs.

**Workflows / complaints.** Users on Trimble's own idea portal call the submittal (and partly RFI) workflow "far behind the curve and very primitive" versus Procore's configurable, response-driven automation, and object to logging a separate "resolution" instead of the design team's approval closing the item ([ProjectSight idea PSW-I-3500](https://projectsight.ideas.aha.io/ideas/PSW-I-3500)). Other dislikes: slow document loading, confusing SCO numbering, occasional bugs; praise: simple, "just enough features", responsive implementation team, value ([G2 alternatives page](https://www.g2.com/products/trimble-projectsight/competitors/alternatives); [TrustRadius](https://www.trustradius.com/products/trimble-projectsight/reviews)).

**Pricing.** Published: **Free** (3 projects, 2 GB, unlimited users, RFIs/submittals/drawings/punch), **Go** $29/user/mo annual (unlimited projects, 15 GB, daily reports, custom roles), higher tiers quoted ([trimble.com/projectsight](https://www.trimble.com/en/products/projectsight); [2024 free-tier announcement](https://investor.trimble.com/news/news-details/2024/Trimble-Expands-Access-to-Advanced-Construction-Project-Management-Capabilities-with-Free-Version-of-ProjectSight-Software/default.aspx)).

**AI.** Dimensions 2025: ProjectSight *Help Agent*, *Auto-Submittals* (generates the submittal register from specs) and *AI Title Block Extraction* GA in North America; *Daily Reports agent* in Labs on mobile; Viewpoint Finance Assistant and Accubid Assistant in Labs early 2026; an open agentic platform for partners ([Trimble, Nov 2025](https://investor.trimble.com/news/news-details/2025/Trimble-Highlights-AI-Strategy-and-Innovation-at-Dimensions-User-Conference/default.aspx)).

## Synthesis

### What makes these the best (common patterns)

1. **One derived "ball in court" field per item, always populated, always a person/org, always with a due date.** Procore, ACC and Aconex all compute BIC from workflow state rather than asking the user to "assign"; an item cannot be open without someone owing the next move. Aconex goes further: *Response required* can be made mandatory at the mail-type level.
2. **A cross-project "what do I owe" inbox is the front door.** Procore My Open Items (sorted by due date), ACC "Assigned to Me", Aconex Tasks (Outstanding / Overdue). The project home then shows *counts by tool in overdue / 7-day / later buckets*, not a wall of stats.
3. **Email is a first-class client, not a notification channel.** Reply-to addresses bound to the item, attachments ingested, responses posted to the record and fanned out. External consultants never need an account or training (Procore, ACC).
4. **Gatekeeper roles.** RFI Manager / Submittal Manager / Coordinator sit between creator and reviewer; the manager decides the official response and closes. Reviewers respond, they do not close.
5. **Formal issue is distinct from sharing.** Transmittals with fixed revisions and a cover note, immutable once sent (Aconex, ACC), with the register recording which revision each party received.
6. **Every event is audit-logged and reported as a cycle-time metric** — days-to-respond per approver (Procore), overdue-by-BIC-organisation (Aconex). Accountability is visible, which is what makes people respond.
7. **Unlimited external users** (Procore, Aconex project model, Buildertrend, ProjectSight Free) — the payer buys the network, not seats.
8. **AI is being pointed at the drafting and summarising chores**, not at decisions: draft RFI, generate submittal register from specs, weekly client update, "what's overdue and why does it matter".

### What they get wrong / why SMEs hate them

- **Price and procurement.** ACV or $35–85/user/mo pricing, demo-gated quotes, 50–75% renewal hikes (Buildertrend), $50k+ implementations. Procore's own sales tells 10-person firms to go elsewhere.
- **Onboarding measured in months** and steep learning curves (all five); tool-to-tool inconsistency inside one product (Procore autosave vs save; Aconex needing register refreshes).
- **Notification floods** with no in-app inbox (top ACC idea request) — the digest is a workaround, not a design.
- **Per-user, per-module licensing** (ACC) that punishes exactly the external parties whose participation the workflow needs.
- **Mobile lags desktop** in every review set.
- **Configuration-heavy workflows** (ACC review templates, Aconex mail-type rules, Procore permission templates) that a one-PM consultancy will never set up — so the good defaults never exist.

### Concrete lessons for E-Site (implementable in v2)

1. **[Procore/Aconex] Make `ball_in_court` a computed column on every RFI/instruction/snag/form**, never NULL while open; creation *requires* an assignee + due date (Aconex "Response required mandatory").
2. **[Procore] Default `due_date` from a per-project "days to respond" setting** per item type, so nobody has to choose one.
3. **[Procore/ACC] Ship a single "My Open Items" page** (cross-project, sorted by due date, buckets overdue / 7 days / later) and make it the post-login landing for every role.
4. **[Procore] Project home = per-module open-item counts with the three-bucket bar** + recently changed; drop any KPI nobody acts on.
5. **[Procore/ACC] Reply-by-email**: mint a per-item inbound address (`rfi-<id>@reply.e-site.live` via Resend inbound), parse the reply + attachments into the item's responses, then fan out — consultants and contractors answer without logging in.
6. **[Procore] Send the BIC-shift email unconditionally** (even when other notifications are muted) and send overdue reminders **only to the current BIC holder** — with a test for the "already-responded assignee" bug Procore's community reports.
7. **[Procore] Split roles: Creator, Manager (E-Site engineer), Assignee, Distribution.** Only the Manager marks the *official response* and closes; assignees respond.
8. **[ACC] RFI/instruction "types" with default assignee per discipline** (e.g. "Electrical query" → the electrical consultant), so assignment is a default, not a decision.
9. **[ACC] Show "Pending action from" alongside BIC** when several people share a step, so partial responses are visible.
10. **[Aconex] Treat instructions, RFIs and variations as typed correspondence with an immutable thread**; sent = frozen; corrections are new mails. This is what makes the record usable in a JBCC dispute.
11. **[Aconex/ACC] Transmittals for drawing issue**: a transmittal records which revision each recipient received; the register shows "transmitted vs latest".
12. **[Procore] Response-time metrics per person/organisation** on a simple report ("avg days to respond, overdue count") — visibility changes behaviour more than reminders do.
13. **[ACC] Per-user notification frequency (instant / daily digest at 04:00) plus an in-app inbox** so email volume drops without losing anything.
14. **[Procore] Scheduled report distribution** — pick a saved report, recipients, PDF/Excel, weekly — for client-facing progress packs.
15. **[Buildertrend] AI weekly client update drafted from daily logs, snags, instructions and forms** — the highest-rated AI feature in this set because it removes a chore, not a decision.
16. **[Aconex/Procore/ProjectSight] Price the network, not the seat**: charge the consultancy per project or per annual volume; contractors, clients and other consultants are free. Publish the price; SMEs cite demo-gated quotes as a reason to walk.
